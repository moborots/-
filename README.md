# # MOBOROOT — سیستم مدیریت تعمیرگاه

نرم‌افزار مدیریت تعمیرگاه با زبان C# و Windows Forms، با هدف مدیریت اطلاعات مشتریان، دستگاه‌های تعمیراتی، تعمیرکاران و امور مالی.

## ✨ امکانات

- مدیریت پذیرش و اطلاعات دستگاه‌های تعمیراتی
- مدیریت مشتریان و تعمیرکاران
- ورود کاربران و مدیریت نقش‌ها
- باز کردن فرم ورود با کلید `F12`
- ثبت دریافت‌ها و پرداخت‌ها
- مشاهده خلاصه وضعیت مالی
- ذخیره‌سازی اطلاعات با پایگاه داده SQLite
- رابط کاربری دسکتاپ مبتنی بر Windows Forms

## 🛠 فناوری‌های استفاده‌شده

- **Language:** C#
- **Framework:** .NET / Windows Forms
- **Database:** SQLite
- **IDE:** Visual Studio
- **Package Manager:** NuGet

## 📋 پیش‌نیازها

برای اجرا و توسعه پروژه به موارد زیر نیاز دارید:

- Windows
- Visual Studio با پشتیبانی از توسعه دسکتاپ .NET
- نسخه سازگار از .NET SDK یا .NET Framework، مطابق با فایل پروژه
- دسترسی به اینترنت برای دریافت بسته‌های NuGet در اولین اجرا

## 🚀 نصب و اجرا

۱. مخزن را دریافت یا Clone کنید:

```bash
git clone <REPOSITORY_URL>
```

۲. وارد پوشه پروژه شوید:

```bash
cd MaintenanceManagement_CSharp
```

۳. فایل `MaintenanceManagement.sln` را با Visual Studio باز کنید.

۴. روی Solution راست‌کلیک کرده و گزینه **Restore NuGet Packages** را انتخاب کنید.

۵. از منوی **Build**، گزینه **Rebuild Solution** را اجرا کنید.

۶. پروژه را اجرا کنید.

> توجه: نام و مسیر فایل Solution ممکن است با ساختار نهایی مخزن متفاوت باشد.

## 🗄️ پایگاه داده

این پروژه از SQLite استفاده می‌کند؛ بنابراین برای اجرای نسخه SQLite نیازی به نصب و راه‌اندازی SQL Server نیست.

از اطلاعات پایگاه داده به‌صورت منظم نسخه پشتیبان تهیه کنید. مسیر و روش پشتیبان‌گیری را مطابق تنظیمات نسخه مورد استفاده بررسی کنید.
