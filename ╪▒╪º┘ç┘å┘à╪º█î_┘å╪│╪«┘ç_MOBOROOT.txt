MOBOROOT — نسخه توسعه‌یافته سورس C# Windows Forms
===================================================

ساختار
- MaintenanceManagement.sln : فایل Solution برای Visual Studio
- MaintenanceManagement/MaintenanceManagement.csproj : پروژه .NET 8 Windows Forms
- پایگاه داده SQLite با ایجاد خودکار جداول هنگام اجرا
- صدور فاکتور از طریق چاپگر Windows «Microsoft Print to PDF» (باید در ویندوز فعال باشد)

اجرا
1) کل ZIP را Extract کنید.
2) در Windows، Visual Studio 2022 و workload «.NET desktop development» یا .NET 8 SDK نصب باشد.
3) فایل MaintenanceManagement.sln را باز کنید، Restore NuGet و سپس Build Solution را اجرا کنید.
4) ورود اولیه: admin / Admin@123 . بلافاصله رمز پیش‌فرض را تغییر دهید.

ذخیره‌سازی و پشتیبان
- برنامه تلاش می‌کند پوشه C:\موبوروت\Backups را بسازد و نسخه پشتیبان SQLite را آنجا قرار دهد.
- اگر ویندوز اجازه نوشتن در ریشه درایو C را ندهد، مسیر پشتیبان به %LOCALAPPDATA%\MOBOROOT\Backups تغییر می‌کند؛ برنامه را با دسترسی مدیر اجرا کنید تا مسیر C:\موبوروت قابل استفاده باشد.
- دیتابیس عملیاتی در %LOCALAPPDATA%\MOBOROOT\maintenance.db نگهداری می‌شود.
- بازیابی از دکمه «بازیابی پشتیبان» انجام می‌شود؛ بعد از بازیابی برنامه را ببندید و دوباره باز کنید.

قابلیت‌های عملیاتی موجود در این نسخه
- ثبت، ویرایش، حذف و جست‌وجوی پذیرش تعمیر؛ شناسه پذیرش خودکار از شناسه رکورد
- گردش موجودی، جلوگیری از خروج بیش از موجودی، هشدار بصری کمبود و کاردکس
- مدیریت کاربران برای مدیر، ظاهر روشن، صفحه اصلی MOBOROOT، داشبورد خلاصه
- تهیه و بازیابی پشتیبان دیتابیس
- فاکتور PDF از طریق Microsoft Print to PDF، با اطلاعات پذیرش و مبلغ
- ساخت جداول پایه برای مشتریان، تاریخچه وضعیت، چک‌لیست، پیوست‌ها، پیش‌فاکتور، خرید و قطعات مصرفی، و شماره سریال فاکتور

محدودیت مهم
این خروجی هنوز پیاده‌سازی کامل همه موارد درخواستی نیست. جداول پایه برای بعضی گردش‌ها ایجاد شده‌اند، اما فرم‌های اختصاصی مشتری، چک‌لیست/پیوست، پیش‌فاکتور و تأیید مشتری، خرید قطعات با هزینه، ثبت مصرف قطعه به تعمیر، گزارش سود و فیلترهای ترکیبی، و اعمال واقعی مجوزهای جداگانه هر نقش هنوز نیازمند توسعه‌اند. فاکتور از سرویس چاپ PDF ویندوز استفاده می‌کند و تولید PDF با کتابخانه داخلی یا لوگوی قابل تنظیم در این نسخه کامل نشده است.

اعتبارسنجی ساخت
در محیط ساخت این بسته ابزار dotnet/MSBuild نصب نبود؛ بنابراین کامپایل واقعی Windows Forms در این محیط قابل اجرا نبود. ساختار فایل‌ها و ارجاع کلاس‌ها بررسی دستی شده، اما قبل از استفاده عملی، روی Windows با .NET 8 SDK حتماً Build و تست دیتابیس انجام دهید.
