# سامانه مدیریت تعمیرات، کاردکس کالا و انبار

## امکانات نسخه جدید
- ورود کاربر با نقش «مدیر» یا «کاربر»
- مدیریت درخواست‌های تعمیر: ثبت، ویرایش، حذف، جست‌وجو و صدور فاکتور PDF با نام تجاری موبوروت
- مدیریت انبار: تعریف کالا، کد یکتا، گروه، واحد، موجودی، حداقل موجودی و محل نگهداری
- ثبت ورود و خروج کالا به انبار با ثبت سابقه گردش
- کاردکس هر کالا شامل تاریخ، نوع گردش، مقدار، شرح و کاربر ثبت‌کننده
- هشدار رنگی برای کالاهای رسیده به حداقل موجودی
- مدیریت کاربران (فقط نقش مدیر): افزودن و حذف کاربر
- SQLite، گزارش رخدادها و هش رمز با PBKDF2

## اجرا
Windows 10/11، .NET 8 SDK و Visual Studio 2022 با workload «.NET desktop development».
فایل `MaintenanceManagement.sln` را باز کنید، Restore NuGet انجام دهید و با F5 اجرا کنید.
یا فایل `اجرای_برنامه.bat` را اجرا کنید.

ورود اولیه: `admin` / `Admin@123`
برای افزودن کاربر، وارد تب «مدیریت کاربران» شوید. این تب فقط برای مدیر نمایش داده می‌شود.
برای ثبت گردش کالا، کالا را در تب «کاردکس کالا و انبار» انتخاب و «ورود به انبار» یا «خروج از انبار» را بزنید.


## صدور فاکتور PDF موبوروت
در تب درخواست‌های تعمیر، یک درخواست را انتخاب و روی «صدور فاکتور PDF» کلیک کنید. فاکتور مرتب شامل شماره فاکتور، تاریخ، تجهیز، درخواست‌دهنده، تعمیرکار، وضعیت، شرح خرابی و هزینه تولید می‌شود. این قابلیت از چاپگر داخلی Windows «Microsoft Print to PDF» استفاده می‌کند؛ در صورت نبودن، باید آن را در Windows Features فعال کنید.
